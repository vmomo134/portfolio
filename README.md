# Portfolio de Oliver Molina de la O

Página estática de portafolio profesional con proyectos de desarrollo web,
automatización e integración de datos.

## Ejecutar localmente

Abre `index.html` directamente en el navegador o sirve la carpeta con:

```powershell
python -m http.server 8000
```

Después visita `http://localhost:8000/`.

## Publicar con GitHub Pages

El repositorio recomendado es `vmomo134/portfolio`. En GitHub activa Pages
desde `Settings > Pages`, selecciona la rama `main` y la carpeta `/root`.

## Personalizar

- Cambia los enlaces de GitHub en `index.html` cuando publiques cada repositorio.
- Sustituye el texto de contacto por tu LinkedIn y correo profesional.
- Agrega capturas públicas en `assets/capturas/` si quieres mostrar demos visuales.

No agregues claves, bases de datos, archivos `.env`, comprobantes ni documentos
institucionales a este repositorio.
